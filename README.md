# EmDash workshop: Ship, Automate, Extend

Code for the hands-on EmDash CMS workshop at CMS Conf 2026 (12–14 Nov 2026), with Matt Kane and Harshil Agrawal.

The workshop guide's prompts fetch from this repo with [giget](https://github.com/unjs/giget), so you normally won't clone it yourself.

| Branch | What's in it |
| --- | --- |
| `checkpoint-a` | The blog after Part 1: the `featured` and `subtitle` fields on the homepage |
| `checkpoint-b` | The blog after Part 2, plus the `cover-images/` plugin starter |
| `checkpoint-c` | The finished `cover-images` plugin, with tests |

Fell behind? Use the guide's catch-up prompt for the checkpoint you need. It copies the code into your site and keeps your own Cloudflare config.
